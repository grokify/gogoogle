# Release Notes: v0.13.0

**Release Date:** 2026-10-30

Adds what a document review round trip needs: upload a file to Drive and
convert it, replace its content in place, and read back the comments, the
suggested edits, and a Sheet of structured responses. Nothing is breaking.

## Highlights

- New `driveutil/v3` package: upload with conversion, update in place, comments
- Suggested edits split into original, inserted, and deleted text
- Sheets read as records keyed by the header row; a CSV published as a Sheet
- `gogoogle drive`, `docs suggestions`, and `sheets records` commands

## New Features

### Drive: upload, update, and comments

```go
import driveutil "github.com/grokify/gogoogle/driveutil/v3"

svc, err := driveutil.NewService(ctx, httpClient)
f, err := svc.Upload(ctx, driveutil.UploadRequest{Path: "review.docx", ConvertTo: driveutil.ConvertDoc})
f, err = svc.Update(ctx, f.ID, "review-v2.docx", driveutil.ConvertDoc)
comments, err := svc.ListComments(ctx, f.ID, driveutil.ListCommentsOptions{})
```

- **Conversion.** `.docx`, `.odt`, `.txt`, and `.html` become Google Docs;
  `.csv`, `.xlsx`, and `.ods` become Sheets; `.pptx` and `.odp` become Slides
  files. A mismatched extension returns `ErrUnsupportedConversion`.
- **Update in place.** The file ID, link, sharing, and comments are kept.
- **Comments.** Each comment has its quoted text, author, resolved state, and
  replies. Listing returns every page or an error, never a partial result.

### Docs: suggested edits

`docsutil.ExtractSuggestionContent` takes a document fetched with
`SUGGESTIONS_INLINE` and returns one block per paragraph and table cell, each
split into original, insertion, and deletion segments, with the original and
as-if-accepted text of the block. The Docs API does not report who made a
suggestion, so blocks carry no author.

### Sheets: records and CSV

`sheetsutil.NewService` creates a Sheets service, like the Drive and Docs
services, so callers need not import the Google client packages directly. It reads
ranges with `GetValues` and `BatchGetValues`. The Slides service gains
`GetPresentation`.
`sheetsutil.ReadRecords` reads a sheet as `[]map[string]string` keyed by the
header row. `sheetsutil.CreateFromCSV` publishes a CSV file as a Sheet.

### Command line

```bash
gogoogle drive upload review.docx --convert doc
gogoogle drive update <fileID> review-v2.docx --convert doc
gogoogle drive comments <fileID>
gogoogle docs suggestions <documentID>
gogoogle sheets records <spreadsheetID> --sheet "Round 1"
```

Output is JSON. Exit status is 0 on success, 1 for an API or input error, and 2
for a usage error.

See the [Drive guide](../guides/drive/index.md).

## Compatibility

Additive only. An API comparison against v0.12.0 reports no incompatible
changes in any package.

## Scopes

Upload and update need `drive.file`. Comments need `drive.readonly`. The guide
lists the narrowest scope for each function.
