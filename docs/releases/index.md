# Releases

Release notes, one file per version, newest first. The
[changelog](changelog.md) is generated from `CHANGELOG.json` and lists every
change with its commit.

The latest release, [v0.12.0](v0.12.0.md), adds Google Search Console in
`searchconsoleutil/v1`.

The previous release, [v0.11.0](v0.11.0.md), adds Sheets cell parsing and URL
utilities, Forms scopes and YouTube short URLs.
