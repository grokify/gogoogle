# Releases

Release notes, one file per version, newest first. The
[changelog](changelog.md) is generated from `CHANGELOG.json` and lists every
change with its commit.

The latest release, [v0.13.0](v0.13.0.md), adds Drive upload with conversion,
comments, suggested edits, and Sheets records for a document review round trip.

The previous release, [v0.12.0](v0.12.0.md), adds Google Search Console in
`searchconsoleutil/v1`.
