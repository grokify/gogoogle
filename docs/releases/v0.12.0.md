# Release Notes: v0.12.0

**Release Date:** 2026-10-21

Adds `searchconsoleutil/v1`, a read-only client for Google Search Console that
signs in with a service account. Nothing is breaking.

## Highlights

- New `searchconsoleutil/v1` package for Google Search Console
- Service account sign-in that requests only the read-only scope
- Search performance, sitemaps and URL inspection in typed results
- Errors that tell unauthorized, forbidden, not found and quota failures apart

## New Features

### Search Console client

```go
import searchconsole "github.com/grokify/gogoogle/searchconsoleutil/v1"

c, err := searchconsole.NewFromServiceAccountKey(ctx, key)
sites, err := c.Sites(ctx)
totals, err := c.Totals(ctx, site, start, end)
```

- **Properties.** `Sites` lists the properties a credential can see and tells
  domain properties from URL-prefix ones. `MatchesDomain` finds the properties
  that cover a domain.
- **Search performance.** `Totals`, `Daily` and `Top` cover the common
  readings. `Query` is the general form, with dimensions, filters, search type,
  data state and paging. Results report the date from which data may still
  change.
- **Indexing.** `Sitemaps` lists a property's sitemaps. `InspectURL` returns
  how Google indexed one page, and `Indexed()` answers the common question.
- **Credentials.** `NewFromServiceAccountKey` accepts only service account
  keys and requests only `webmasters.readonly`. `ServiceAccountEmail` returns
  the address to add as a user on each property. `New` takes any authorized
  `*http.Client`.
- **Errors.** Failed calls wrap a sentinel (`ErrUnauthorized`, `ErrForbidden`,
  `ErrNotFound`, `ErrQuotaExceeded`) and the underlying Google error, so both
  `errors.Is` and `errors.As` work.

See the [Search Console guide](../guides/searchconsole/index.md).

## Dependencies

- `golang.org/x/oauth2` is now a direct dependency.
- Updated `google.golang.org/api`, `google.golang.org/grpc`,
  `cloud.google.com/go/bigquery`, `github.com/grokify/goauth`,
  `github.com/grokify/mogo` and `github.com/grokify/gocharts/v2`.

## Upgrade Notes

No code changes are needed. Add the service account's email as a user on each
Search Console property before reading it.
